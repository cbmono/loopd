LOOPD · THE LOOP, RUNNING

You steer.
They build.
Two gates stay yours.

loopd is a Claude Code plugin that runs a small team of AI agents on your repositories. You describe the work. They plan it, build it and get it reviewed. You promote, and you merge.

THE LOOP

Five stops. Two of them are yours.

The agents work in their lane. The flow only drops into yours twice: nothing is dispatched until you promote, and nothing reaches main until you merge.

INSTALL

From install to your first Pull Request.

Needs Claude Code, git, gh (logged in) and bash. The plugin installs once per machine. Each group of repositories gets its own bundle: a small git repo that holds plans, tasks and notes, never application code.

Two or three people can share one bundle; each project has an owner.

Getting started guide → Sharing a bundle → Handing over tasks to your team →

SAFETY RAILS

None of them is decoration.

Independent review

Every PR is cleared by a reviewer with fresh context, never the implementing agent’s own report.

enforced by review-clearance.sh

Exit 0 is the only clearance

Missing, pending, skipped and unreadable checks all refuse. So does a reviewer that declined to review.

enforced by required-checks.sh

Destructive commands are blocked

A hook stops shapes like terraform destroy, force-pushes to protected branches and rm -rf of a repo root.

enforced by deny-destructive.sh

Never deletes on a guess

The worktree pruner only reports, and bundle repair is report-only by default. Stale means ask the human.

enforced by prune-worktrees.sh

The gates can be delegated

Only through the separate loopd-yolo plugin, and only for projects set to autonomy: yolo. Uninstall it and every project on this machine is gated again.
