The release cut. Everything before this was a slice of the move from a symlinked
template to an installable Claude Code plugin; this is the version that says so.

**91 merged pull requests since `pre-rebase-r8`** (the last tag), grouped below.
Every one is linked; the five groups are the five things that changed.

## Install

The whole delivery model changed. 0.36.0 was a git checkout you cloned, symlinked into
each bundle with `install.sh`, and updated by pulling. 1.0.0 is a **plugin**: one install
per machine, `/ai-bridge:init` to stamp a bundle, and a bundle that carries **no machinery
and no link into any checkout**. `install.sh` is retired.

```text
/plugin marketplace add cbmono/ai-bridge
/plugin install ai-bridge@ai-bridge
/ai-bridge:init ~/workspace/<group>/_ai-bridge-<group>
```

**Upgrading an existing install: [`docs/migrating.md`](../migrating.md).** It converts in
place — `projects/` and `knowledge/` are never touched — or re-homes into a fresh folder.
**New to it: [`docs/first-hour.md`](../first-hour.md)** — one page, install to first
dispatch.

**`ai-bridge-v2` is gone.** The transition name shipped a one-version deprecation stub;
1.0.0 removes it, so the only marketplace entries are `ai-bridge` and the
`ai-bridge-yolo` companion.

## Gates

The two human authorities — only a human promotes `draft -> ready`, only a human merges —
became mechanical rather than remembered. A `PreToolUse` deny baseline refuses a merge, an
approval, a destructive action and a push to a protected branch **before the tool runs**;
the review cap is countable; the PR body has a reader; and one dispatch lock keeps the loop
serial.
