## The three bugs

- **`push-state.sh` died silently on an unreadable document** when `find` listed it last:
  a `while … && …` loop's last status under `set -e` ended the hook with no output. macOS
  passed because of directory order; the guard was order-dependent for months (#367).
- **Every repaired or refreshed file ended `0600` on Linux**: `stat -f '%Lp' || stat -c '%a'`
  reads the FILESYSTEM on GNU `stat`, fails, and the fallback's output was appended to the
  failure's — `chmod` refused. `migrate-bundle.sh`, `close-project-folder.sh`,
  `refresh-seeds.sh` now probe `stat -c` first and validate the result as octal (#367).
- **A role agent's brief could carry a `Broken pipe` line**: `dispatch-brief.sh` capped its
  grounding section with `awk … exit` mid-pipe; where SIGPIPE is ignored the upstream
  `printf` reports the error into the body. The cap now consumes its input (#369).

## The gate moved to Linux (#368)

Measured 2026-10-09: macOS 16m 37s / 2,494 harness-seconds on 3 cores; Linux 6m 32s /
1,285 on 4 cores, 152 of 152 harnesses green after the fixes above. The workflow comment
keeps the 2026-08 reasons macOS was chosen and the measurements that moved it. The nightly
macOS job is advisory. `timeout-minutes` is 20; the warn-only budget is 2,000
harness-seconds. One unexplained flake (`awaiting-queue`, once in three runs) is on watch.

## The release question

*For each hook, gate and script, which assumption has this model generation made
unnecessary?* None. One assumption about the TESTS was found false: that a green suite on
one platform proves the scripts. Two of the three bugs had passing tests whose pass
depended on `readdir` order and on `stat`'s dialect.
