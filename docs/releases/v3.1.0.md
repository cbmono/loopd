# loopd 3.1.0

**The bundle's state directory can move from `.ai-bridge/` to `.loopd/`.** 3.0.0 renamed the
plugin, the commands and the role-agent namespace but deliberately left `AB_DIR` alone, because
renaming the state directory and the plugin in one release would have made every bundle
unreadable by the version that stamped it. This release ships the migration that closes that gap.
**Nothing moves on its own** — `migrate-bundle.sh` is dry-run by default, and `AB_DIR` still
resolves to `.ai-bridge` until a later release flips it.

**34 merged pull requests since 3.0.0.**

| | |
|---|---|
| **Upgrading** | `/plugin update`, then `/loopd:init` in each bundle. Run `migrate-bundle.sh` to preview the `.loopd/` move and `--apply` to take it |
| **Breaking** | None. A 3.0 bundle keeps working untouched |
| **New config** | `ticketPrefix` — absent means a PR title carries no bracketed ticket tag at all |

---

## The state directory moves

`migrate-bundle.sh` moves `.ai-bridge/` to `.loopd/` in one idempotent pass (#306). Four things
travel together, because any one of them left behind leaves a half-migrated bundle:

| | |
|---|---|
| the directory | `git mv` where git tracks it, plain `mv` where it does not |
| `.gitignore` | driven to zero `ai-bridge` references — the count differs per bundle, so no fixed number is right |
| the statusline pin | rewritten as a whole absolute path with `jq`, the parse validated either side |
| a mounted KB's `core.worktree` | repointed, because `kb.git` is gitignored and `git status` cannot see it go wrong |

A second run changes nothing and says so.

## The ticket tag is no longer one organisation's

A PR title carried `[DPT-0]` — a hardcoded Jira project key — on every installation (#307).
The fallback is now **no tag at all**; set `ticketPrefix` to get one.

## Gates and clearance

- `pr-body-clearance` stops charging verbatim criterion text against the 2,500 ceiling (#303),
  so a PR can quote its criteria in full instead of silently paraphrasing them.
- `validate-bundle.sh <path>` leaves the index drift check out (#301), and
  `review-clearance`'s already-asked hold names `full review` where it already knows it (#277).
- Every command a notice prints is now probed with stated dummies and parsed (#280, #288, #298) —
  a notice that prints a command is a contract the harness executes.

## Dispatch and agent control

- **The wall-clock cap clocks the agent, not the session transcript** (#305). The old fallback
  measured a shared file's age, so every agent in a long session reported the same elapsed time
  and had its handback refused — a working loop that looked silent.
- The status line shows which agent sessions have a live process (#299); `reclaim-worktree.sh`
  removes a merged task's worktree (#287); a stable scripts path for the operator's terminal (#300).
- `AWAITING.md` is ordered so it can be worked top to bottom (#295), and the served board shows
  the open question's text (#296).

## Knowledge base

- A scheduled run proposes `knowledge/` merges; `/loopd:kb-apply` applies them (#283).
- Briefs' citations are stored, and an uncited Finding is proposed for archive only past every
  qualifier (#294) — a retire-on-silence rule needs a floor on the signal itself.
- `kb-sync` clones over the bundle's own transport (#291), and each knowledge item carries a
  per-item ledger in its frontmatter (#272).

## Schema and intake

- **The value gate** — `need`, `cost_of_not_doing`, `no_owner` (#278): the three questions that
  were free when building was expensive.
- `timebox:` marks a project as an experiment allowed to die (#292).
- The `Needs you` reply vocabulary ships in the seed, **with promote and merge carved out of it**
  (#302) — those two are the human authorities, and a shorthand that fires either from two
  characters moves an authority into a typo.
- A bundle's group comes from its config, not its directory name (#282).

## Harness

- **The YAML oracle is chosen by conformance, not import order** (#285). The same commit read
  56/0 on CI and 54/2 locally until this landed.
- Frontmatter lists are one quoted entry per line, and every reader reads it (#297).
- Every agent body names a `CONVENTIONS.md` that resolves (#286); seed doc links resolve after a
  stamp (#281); closeout removes its own derived index and names leftovers (#274); `--stage`
  accepts a path `git rm -r` already removed (#275).

## Brand

Accents ship beside the primary blue/pink pair (#284); brand prose follows the loopd flip, pinned
by a hand-classified survivor list (#289); the welcome wrapper spells the brand through
`$PLUGIN_NAME` (#290).
