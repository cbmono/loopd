# loopd 3.7.0

**loopd carries one brand on every surface.** The board follows your system's light or
dark theme and marks finished work green, pink is reserved for what only a human can
clear, and the status line and the transcript use the same green: running agents on the
status line, and your own past prompts in the history.

## One brand on the board and the pane (#387)

- **Light theme.** `build-board.sh` adds a `prefers-color-scheme: light` block, so the
  board follows the system setting. Pink text and pink fill are separate variables, so
  needs-you rows and buttons stay readable in light.
- **Green means done.** A new `--done` token (#76d6a4 dark, #18794c light) marks sent,
  saved and finished work. Machine states stay blue. The theme's `success` moves to
  #76d6a4.
- **Pink only where a human is needed.** A test holds every pink rule to one named
  allowlist of human-gated rows and controls; what was pink and not human-gated moved off
  it.
- **The pane draws needs-you rows pink.**

## Green for running agents and your prompts (#394)

- **Status line.** `agents N running` is painted 24-bit #76d6a4 whenever N > 0, at any
  colour tier, so it is the brand's green and not the terminal palette's. 0 stays dim;
  `?` and `no process` stay pink. The code is spelled once, as `T_GREEN` in
  `cli-theme.sh`.
- **Transcript.** The loopd theme sets `userMessageBackground` to #223132 (hover
  #2a403c) and `briefLabelYou` to #76d6a4, so your past prompts stand out when you scroll
  the history. Text stays #f5f5f5.
- **A deliberate exception.** Running agents are machine progress, which the design keeps
  blue; making them green is the owner's call, written down in `cli-theme.sh`'s header and
  not a precedent for other surfaces.
