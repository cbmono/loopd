## Banner Board row is the served URL

- **When the server answers**, the banner's `Board` row is the clickable `http://localhost:<port>/loopd/board` and the `Run` row points at `--help`; the `file://` row is printed only when nothing serves, with the Run row naming why (`boardServe: false`, python3 missing, port held) (#452).
- **With an artifact recorded**, the artifact stays the `Board` headline and the served URL is its dim continuation line (#452).
- **`/loopd:board --help`** (and `help`) prints the three forms, serve, publish and `--help`, one line each; any other argument is still a typo naming all three (#452).
- **The held-port cause** comes from `board-session.sh start`, which prints `held <port>` when `board-serve.sh` exits 3 (#452).

## Mods test green on Claude Code 2.1.310

- **`tests/mods.test.sh`'s zero-warnings pin drops only the CLI's closed plugin-directory block** (`Plugin directory checks for …` to `These plugin directory checks do not change the result below.`) before counting `warning`; any other warning still fails, and real 2.1.310 output fixtures under `tests/fixtures/mods-validate/` pin a manifest warning beside the block and an unclosed block (#454).
- **The counted line was `ICON_MISSING`** inside that block, not the "names a hooks module" notice; the mods themselves are unchanged (#454).

## Docs

- **What the `explorer` tier is**: README "The team", the SCHEMA seed and `docs/operations.md` say that `plan-architect` and `explorer` are `roleTiers` rows and not team members, what Claude Code's built-in Explore subagent does, who dispatches it, and what deleting the row costs (#453).
