## The banner (#401)

- **Header beside the mark.** The SessionStart banner prints `loopd v<ver> · <bundle> ·
  org: <org>` on the logo's middle row and its rule on the bottom row, so the mark and the
  identity read as one three-line block. Colours are unchanged: bold ink header, dim rule,
  pink gate and arrow, blue tube.
- **Every channel.** The text banner, the `/loopd:welcome` markdown relay and the hook's
  `systemMessage` carry the same shape; with the logo off the banner is byte for byte the
  old two lines.
- **`release-bump.sh` follows it.** The rule under a displayed header is resized from the
  header's own column, so a doc that shows the banner beside the mark stays in step.

## Reclaim (#399)

- **Build output no longer blocks a merged worktree.** The ignored-content guard (G12) lets
  a worktree go when everything it holds is regenerable output: `dist`, `build`, `out`,
  `coverage`, plus any names an optional `reclaimIgnoreOk` key adds. A `.env*` name is never
  accepted there.
- **A refusal says what to run.** It ends with the exact `git -C <worktree> clean -fdX --
  <paths>` line.

## The release question

*For each hook, gate and script, which assumption has this model generation made
unnecessary?* None. Both changes remove friction a human hit; neither retires a gate.
