# loopd 3.8.0

**A yolo project can now merge on an external review, a new project reaches every
clone, and the web board's inbox carries the questions it shows.** Four papercuts from
the 2026-10-09 pass are fixed along the way: validate-bundle's false SKIP, reclaim
refusing itself, briefs naming pnpm, and the devops role's destructive deletes.

**7 merged pull requests since 3.7.0.**

| | |
|---|---|
| **Upgrading** | `/plugin update` (or `claude plugin update loopd-all`), restart Claude Code. No stamp needed |
| **Check it** | `validate-bundle.sh` ends with `checked N, skipped M`; `/loopd:new-project` prints the push it made |
| **Breaking** | nothing. A delegated merge on a repo whose only reviewer is an external vendor now fires where it was refused before — that is the point of #395, and it only applies where `AUTONOMY.md` delegates merging |

---

## Delegated merges (#395)

- **An external review stands in for the checker table.** Where a REVIEWERS vendor (e.g.
  CodeRabbit) cleared the PR's head, a delegated merge no longer also needs a checker
  table, as `AUTONOMY.md` already documented. A checker FAIL still refuses.
- **The gate guards itself.** A PR that edits the gate's own files is always the human's
  (`required-checks.sh` exit 4).

## Shared bundles and the web board

- **A new project is pushed** (#386). `/loopd:new-project` pushes its commit through a
  new `push-commit.sh`, the pull/push tail extracted from `answer.sh`, so a project created
  on one clone reaches the other clone's loop. Nothing is ever force-pushed.
- **The served board's inbox has its content** (#388). `board-serve.sh`'s serve-time fill
  now carries each open question's text, options and depths, and each project's need and
  success criteria. `SNAPSHOT.json` gains no field.

## Papercuts

- **validate-bundle never SKIPs a document it checked** (#391). Every `printf | grep -q`
  under `pipefail` is a here-string, so a file list over 64 KiB no longer prints a false
  SKIP; SKIPs are counted apart from checks, and knowledge month shards are ignored.
- **reclaim no longer refuses itself** (#390). The live-process guard (G13) skips
  reclaim's whole caller chain, so a shell whose command line names the worktree no
  longer blocks it; any other process still does.
- **Briefs name the repo's own package manager** (#392), as its `CLAUDE.md` states,
  instead of pnpm; refine no longer drafts browser criteria for an app with no known
  login.
- **devops-engineer never runs a destructive vendor-CLI deletion in-session** (#389). It
  writes the exact command into `open_questions` and sets the task `blocked`.

## The release question

*For each hook, gate and script, which assumption has this model generation made
unnecessary?* One: that a delegated merge needs a second, in-house checker even after an
external reviewer has cleared the exact head. #395 retires it where the documented rule
already did, and keeps the human for any PR that edits the gate itself.
